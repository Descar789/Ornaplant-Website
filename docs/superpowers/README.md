# Superpowers workspace

Esta carpeta sigue la convencion del framework Superpowers para que distintos
agentes puedan encontrar specs, planes y aportes dentro del repo.

## Ubicaciones

- `specs/`: documentos de diseno aprobados.
- `plans/`: planes de implementacion ejecutables por agentes.

## Plan activo

- `plans/2026-05-31--admin-panel-refactor.md`

El plan tambien tiene una copia colaborativa en:

- `ai-collaboration/refactor-admin-panel.md`

Si un agente agrega informacion nueva, debe actualizar el plan activo o dejar una
nota clara con fecha, autor/agente y motivo tecnico.
