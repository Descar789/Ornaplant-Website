# Carpeta de colaboracion IA

Esta carpeta es el punto compartido para planes, revisiones y aportes de Codex,
Claude, Gemini u otros asistentes sobre este proyecto.

## Reglas de uso

- Usar esta carpeta en lugar de rutas temporales como `.gemini/tmp`.
- Mantener los planes en Markdown con nombres claros.
- Agregar aportes como secciones nuevas o cambios directos al plan, indicando el
  motivo tecnico cuando sea importante.
- No mezclar implementacion con planeacion: los cambios de codigo van en sus
  archivos reales del proyecto.
- Si un plan cambia alcance, actualizar primero la fase afectada y sus criterios
  de aceptacion.
