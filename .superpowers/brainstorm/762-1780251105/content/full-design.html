Flujo de datos

admin.html carga → auth.js init()
  token existe + no expirado → panel.js initPanel()
  token ausente o expirado → mostrar login

Login: signIn() → api.adminLogin() → sessionStorage → initPanel()

initPanel(): Promise.all([getPlants, getGlobalVisits])
  → renderStats() + renderList()

Crear: openModal(null) → validar → api.createPlant(data)
  → server devuelve {id} → plantList.push → toast success

Editar: openModal(id) → validar → api.updatePlant(id, data)
  → plantList[idx] actualizado → toast success

Borrar: 2-click confirm → api.deletePlant(id)
  → plantList.filter → toast success

Disponibilidad: optimistic update → api.updatePlant()
  falla → rollback valor + renderList() + toast error
